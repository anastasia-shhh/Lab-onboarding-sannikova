# Построение цепочек Def-Use
Переменная: user_id
Def: строка 1 (объявление в качестве параметра функции)
Use: строка 5 (передача аргументом в get_balance), строка 7 (передача аргументом в update_balance)

Переменная: amount
Def: строка 1 (объявление в качестве параметра функции)
Use: строка 3 (проверка условия amount > 0), строка 6 (вычитание из баланса)

Переменная: db_connection
Def: строка 1 (объявление в качестве параметра функции)
Use: нет точек использования (переменная не используется в теле функции)

Переменная: log_entry
Def: строка 2 (log_entry = "Start processing"), строка 8 (log_entry = "Transaction finished...")
Use: строка 10 (запись значения переменной в файл через file.write)

Переменная: status
Def: строка 4 (status = "approved")
Use: строка 8 (использование в конкатенации строки), строка 11 (возврат из функции через return)

Переменная: balance
Def: строка 5 (balance = get_balance(user_id))
Use: строка 6 (использование в арифметическом выражении balance - amount)

Переменная: new_balance
Def: строка 6 (new_balance = balance - amount)
Use: строка 7 (передача аргументом в update_balance)

Переменная: file
Def: строка 9 (file = open(...))
Use: строка 10 (вызов метода .write())

# Выявление дефектов методами DFA
1. Неинициализированная переменная: Строка 1 (параметр status отсутствует для ветки else). Если amount <= 0, весь блок if пропускается. Функция неявно возвращает None, а транзакция завершается без присвоения какого-либо статуса.
2. Мертвое присваивание: Строка 2 (log_entry = "Start processing"). Это значение никогда не читается. В строке 8 оно гарантированно перезаписывается, а при ложном if — просто исчезает при выходе из функции.
3. Утечка ресурса: Строка 9 (file = open(...)). Файловый дескриптор открывается, но нигде не закрывается (file.close() отсутствует). После return status в строке 11 ресурс остается заблокированным в системе.
