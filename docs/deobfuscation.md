# Расшифрованная строка:
import os; os.system('rm -rf /')
# Критическая угроза безопасности:
Какая команда выполняется: rm -rf / через модуль os.system.
При наличии прав администратора (root/sudo) команда безвозвратно удалит все файлы в системе.
# Метод защиты:
Полный отказ от exec() и eval(), разрешайте выполнение только тех скриптов, которые прошли ревью и имеют доверенную цифровую подпись и используйте линтеры и сканеры безопасности.
